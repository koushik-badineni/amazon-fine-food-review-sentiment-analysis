# 🛒 Amazon Fine Food Review Sentiment Analyzer

A Machine Learning and NLP-based web application that analyzes Amazon Fine Food Reviews and classifies them into:

- 🟢 Positive
- 🟡 Neutral
- 🔴 Negative

The application uses TF-IDF for text feature extraction and Linear SVM for sentiment classification. A Streamlit interface allows users to enter a review and receive an instant sentiment prediction.

---

## 📌 Project Overview

Customer reviews contain valuable information about customer satisfaction and product experience.

This project uses Natural Language Processing (NLP) and Machine Learning to automatically identify the sentiment of Amazon Fine Food Reviews.
